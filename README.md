# MODU — Modified by You

ต้นแบบตลาด Digital Product โทนดำ–ขาว พร้อมตัวอย่าง Spreadsheet และระบบคำขอปรับแต่งจากผู้ขายเดิม

## ฟังก์ชันที่ทดลองได้
- ค้นหา กรองหมวด ประเภทไฟล์ ราคา และเรียงสินค้า
- ดูสินค้า โปรไฟล์ผู้ขาย ทดลองเครื่องมือ และบันทึกรายการโปรด
- ซื้อจำลอง แล้วดาวน์โหลดไฟล์ HTML สาธิต
- ผู้ซื้อส่งคำขอปรับแต่งตรงไปยังผู้ขายเดิม พร้อมงบและกำหนดส่ง
- Seller studio: เลือกผู้ขาย เสนอราคา ส่งมอบงาน และเพิ่มรายการสินค้าเดโม
- ผู้ซื้อตอบรับ/ปฏิเสธข้อเสนอ ยืนยันรับงาน และรีวิว
- บันทึกข้อมูลเฉพาะเบราว์เซอร์ด้วย localStorage และล้างเดโมได้

## ขอบเขต
ไม่มีการเก็บเงินจริง ไม่มีบัญชีจริง ไม่มีการส่งคำขอไปยังบุคคลภายนอก และไม่มีฐานข้อมูลร่วมระหว่างผู้ใช้
ผู้ขาย คะแนนรีวิว ราคา และข้อมูลในภาพเป็นตัวอย่างสำหรับนำเสนอ สินค้า Excel ในแค็ตตาล็อกไม่ได้ส่งมอบไฟล์ .xlsx เชิงพาณิชย์
GitHub Pages ใช้แสดงต้นแบบเท่านั้น ระบบจริงต้องเพิ่ม backend, authentication, payment และการจัดเก็บไฟล์ที่ปลอดภัย

## ปรับแต่งต่อ
- `app.js`: ข้อมูล PRODUCTS / SELLERS และฟังก์ชันต่าง ๆ
- `styles.css`: สี เลย์เอาต์ และส่วน MODU contrast refresh ท้ายไฟล์
- `index.template.html`: หัวเว็บ เมนู และ footer
- `assets/`: ภาพตัวอย่าง SVG ที่สามารถเปิดหรือแก้ไขได้
- หลังแก้ source ให้รัน `node build-single.cjs` เพื่อสร้าง `index.html` ใหม่ แล้วอัปโหลด index.html ที่สร้างใหม่
- ใช้ `node smoke-test.cjs` ตรวจขั้นตอนธุรกิจ และ `node serve.cjs` เปิด localhost:4173 (ต้องว่าง)

## การตรวจสอบ
ดู QA.md สำหรับสิ่งที่ตรวจแล้วและข้อจำกัด ไม่ต้องมี Node เมื่อต้องการเปิดหรือ deploy ไฟล์ index.html ที่เตรียมไว้
